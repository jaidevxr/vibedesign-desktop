## What is this?

VibeDesign Desktop is an **AI-assisted UI/UX design platform** that lets you describe what you want to build in plain English and get instant, editable design outputs. Built with a sleek desktop-like interface, it combines the power of AI generation with hands-on design editing — perfect for rapid prototyping and design exploration.

## Features

- 🤖 **AI-Powered Generation** — describe your UI and watch it come to life
- 🎨 **Visual Editor** — fine-tune generated designs with an intuitive interface
- 🌙 **Dark/Light Mode** — seamless theme switching with `next-themes`
- 📊 **Data Visualization** — built-in charting with Recharts
- ⚡ **Real-time Preview** — instant feedback as you design
- 📱 **Responsive** — works across all screen sizes

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **UI Components**: Radix UI, Tailwind CSS, shadcn/ui
- **State Management**: TanStack React Query
- **Routing**: React Router v6
- **Charts**: Recharts
- **Deployment**: Vercel

## Getting Started

```bash
git clone https://github.com/jaidevxr/vibedesign-desktop.git
cd vibedesign-desktop
npm install
npm run dev
```
